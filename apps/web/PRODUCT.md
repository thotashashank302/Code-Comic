## Product Purpose

Explain a GitHub repository as four evidence-linked comic panels. Preserve the
web workspace, Chrome side panel, source inspection, generation, evidence,
download and deletion workflows already implemented.

## Operating Context

The user evaluates their own project in a local web preview and Chrome extension.
GitHub and image-provider quotas make repeated live inspection difficult. A clearly
labeled bundled sample must allow visual review without either API.

## Capabilities and Constraints

Local mode supports public repositories and free structural analysis/template
artwork. OpenAI/Gemini image generation is optional and uses the user's own key and allocation; captions and evidence remain unchanged.
Hosted private access and sharing require configured services. Sample content
must never imply a fresh scan, live verification or successful paid generation.

## Brand Commitments

Keep the Comic Code name and components. The user explicitly replaces the violet
appearance with the supplied light SaaS mosaic reference: neutral canvas,
chartreuse, pink, cool blue and peach surfaces, dark text, rounded white chrome,
and Plus Jakarta Sans. Adapt the composition to actual product controls and a
narrow extension. The reference asks for no external images and SVG geometry.
